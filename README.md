## Workflow

Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening your first pull request.

- `main` is protected: no direct pushes, every change goes through a PR with at least one approval.
- Issues live in [GitHub Issues](https://github.com/KakkoiSchool/aria/issues). Use them to track work.
- Chat: [Discord](https://discord.com/invite/YrtdssGUJa). Channel `#dev` for build chatter, `#deploys` for deploy notifications.
